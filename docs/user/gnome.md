# Shortcuts window and GNOME

## Keyboard shortcuts

Press `Ctrl+?` (`Cmd+?` on macOS), or choose **Keyboard shortcuts** in the command palette or the
desktop **Help** menu, to see every shortcut in one window. It lists what is bound now, in the same
groups as **Settings → Keybindings**, so a key you changed shows its new value. Kodo's own
shortcuts are under **Kodo**: `Shift+Tab` cycles the interaction mode, and the sub-agents and
Orchestrator commands show **Not assigned** until you bind a key to them. Press the chord again or
`Esc` to close it. It works the same on every platform and in the browser.

## GNOME (Linux desktop app)

On GNOME, the window has no system title bar. Kodo Code draws its buttons in its own header bar, on
the side and in the order of your GNOME button layout (`org.gnome.desktop.wm.preferences
button-layout`). Drag the header to move the window; double-click it to maximize, as GNOME is set to.
Other Linux desktops, and any desktop where the layout cannot be read, keep the system title bar.

**Settings → General → Use system title bar** switches back to the system title bar. It takes effect
the next time Kodo Code starts.

The Kodo theme also takes GNOME's accent colour (Settings → Appearance in GNOME), and follows a
change while Kodo Code is open. Choosing another theme keeps that theme's own accent, and
**Settings → General → Follow the system accent colour** turns it off for the Kodo theme.
